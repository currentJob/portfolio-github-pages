### 📌 프로젝트 개요
정확한 AI 학습 모델 개발을 지향하는 기초 체력인 "빅데이터셋"을 구축하기 위해 200만 건 이상의 방대한 데이터를 수집·가공·저장하는 고효율 ETL 파이프라인과 저작 도구를 체계적으로 기획 및 운영했습니다.

### 💡 주요 기능 및 구현 포인트
- **웹 저작 도구 고도화**: Spring MVC 프레임워크 기반의 웹 기반 데이터 저작 도구를 유지보수하고, 기능 개선 최적화를 수행.
- **마이그레이션 자동화 배포**: 기존 웹 저작 도구 환경을 Docker 기반 컨테이너 기반으로 성공적으로 이관, 복제 및 배포 자동화와 운영 환경 표준화 완료.
- **대용량 데이터 품질 관리**: 200만 건 이상에 달하는 메타 데이터들을 효과적으로 트래킹하기 위해 데이터 조회, 필터링 로직 구현.
- **비식별화 기반 오토메이션**: CNN 모델 기반 헬멧 미착용자 자동 검출, 개인정보 보호를 위한 자동 Blur 처리(비식별화) 프로세스 구축.

### 🏆 업무 성과
반복적이고 번거롭던 이미지 비식별 처리 작업을 선제적으로 자동화하여 전체 사업에서 가장 중요한 가공 소요 시간을 대폭 줄이고 많은 인건비를 아낄 수 있었습니다. ETL 데이터 파이프라인을 구축해 대규모 국책 사업을 안정적인 기한 내 성공적으로 준공처리했습니다.
